## AWS IAM User Creation

After creating my AWS account, I proceeded with creating a separate IAM (Identity and Access Management) user to manage access to AWS services for my DevOps project.

I logged in to the AWS Management Console using my root account and navigated to the IAM service. From there, I created a new IAM user named `Balachandra`.

During the user creation process, I configured the required access permissions so that the IAM user could access the AWS services needed for this project. I also reviewed the available permission policies and assigned the appropriate permissions.

After completing the configuration, I created the IAM user and generated the required access credentials for programmatic access to AWS services through the AWS CLI.

I securely stored the generated credentials for future use and made sure not to expose them in my GitHub repository.
