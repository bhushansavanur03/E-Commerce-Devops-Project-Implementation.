1. About This Project

I am working on an E-Commerce application as part of my DevOps learning journey.
I came across this project while learning DevOps and decided to implement it myself to get practical experience with different tools.
My main intention is to understand how an application goes from source code to deployment. I also want to learn how different DevOps tools work together instead of studying them individually.

2. Understanding the Application

Before starting with the DevOps implementation, I need to understand the application itself.
An E-Commerce application is an online shopping platform where users can browse products, and items to their cart and place orders.
I will first explore the application's source code and understand its structure before moving towards Docker, AWS and other DevOps tools.

3. My Implementation Plan

These are the tools and technologies I will be exploring during this project:

- Git and GitHub – For source code management.
- AWS – For cloud infrastructure.
- Terraform – For creating infrastructure using code.
- Docker – For containerizing the application.
- Kubernetes – For managing and deploying containers.
- GitHub Actions – For automating the CI/CD process.
- Argo CD – For learning GitOps and application deployment.
